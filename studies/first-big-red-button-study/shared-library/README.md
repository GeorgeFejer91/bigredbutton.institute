# Shared Library

This folder is the cross-project index for assets and knowledge that matter to
both the native Quest/XR study and the Unity app.

## Index

- `button-assets.md` - Button model, glow, and press-sound asset catalogue.
- `language-and-tts.md` - Localized audio, transcripts, ElevenLabs, and
  validation protocols.
- `research-and-for-ai.md` - Publication, HCI, hand mechanics, and For-AI
  knowledge map.
- `versioning.md` - How to update the MesmerPrism Unity subtree and keep
  generated outputs out of Git.

Use these files as the first stop before copying assets between project folders.
Every reusable asset should have a source path, SHA-256, license/provenance, and
current consumer recorded here.
